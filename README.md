Liora - Batik and Handcraft E-Commerce Web Application
Liora is a user-friendly e-commerce platform designed to promote and sell Sri Lankan batik and handcrafted products. Built using the MERN stack, it provides a seamless shopping experience for users and efficient inventory management tools for sellers.

Key Features

User Authentication: Secure registration and login with JWT.
Product Showcase: Organized categories with visually appealing designs.
Cart & Checkout: Add items, select sizes/quantities, and proceed to checkout.
Payment Integration: Online banking for secure transactions.
Order Notifications: Automatic order emails to sellers via EmailJS.
Admin Panel: Manage products with add, update, and delete functionalities.

Technologies Used

Frontend: React.js, Tailwind CSS
Backend: Node.js, Express.js
Database: MongoDB
Email Integration: EmailJS

Achievements

Scalable architecture for multiple users and product categories.
Optimized performance for faster loading times.
Clean and intuitive UI for enhanced user engagement.

Getting Started

Clone the repository.
Install dependencies using npm install.
Run the frontend and backend with npm start for React and npm run dev for Node.js.
