# Liora - Batik and Handcraft E-Commerce Web Application 🌟

**Liora** is a user-friendly e-commerce platform designed to promote and sell Sri Lankan batik and handcrafted products. 🧵🖌️

## Key Features ✨
- 🔒 **User Authentication**: Secure registration and login with JWT.  
- 🛍️ **Product Showcase**: Organized categories with visually appealing designs.  
- 🛒 **Cart & Checkout**: Add items, select sizes/quantities, and proceed to checkout.  
- 💳 **Payment Integration**: Online banking for secure transactions.  
- 📧 **Order Notifications**: Automatic order emails to sellers via EmailJS.  
- 🛠️ **Admin Panel**: Manage products with add, update, and delete functionalities.  

## Technologies Used 💻
- **Frontend**: React.js, Tailwind CSS  
- **Backend**: Node.js, Express.js  
- **Database**: MongoDB  
- **Email Integration**: EmailJS  

## Getting Started 🚀
1. Clone the repository.  
2. Install dependencies using `npm install`.  
3. Run the frontend and backend with `npm start` for React and `npm run dev` for Node.js.
